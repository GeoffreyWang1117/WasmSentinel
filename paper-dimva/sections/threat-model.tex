\section{Threat Model}
\label{sec:threat-model}

This section formalizes the adversary model, defines our security goals, and establishes the trusted computing base (TCB) for \textsc{WasmSentinel}.

\subsection{Adversary Model and Capabilities}

We define a formal adversary model based on the capabilities available to an attacker at different stages of an intrusion. We distinguish between three levels of adversary capability, summarized in Table~\ref{tab:adversary-capabilities}.

\begin{table}[h]
\centering
\caption{Adversary Capabilities and Attack Vectors.}
\label{tab:adversary-capabilities}
\begin{tabular}{lp{5cm}l}
\toprule
\textbf{Level} & \textbf{Description} & \textbf{Capabilities} \\
\midrule
$\mathcal{A}_{ext}$ & \textbf{External Attacker}: Initial access via vulnerable service. & Network access, User-level execution. \\
$\mathcal{A}_{loc}$ & \textbf{Local Attacker}: Gained persistence, seeking escalation. & File system access, Syscall invocation. \\
$\mathcal{A}_{rule}$ & \textbf{Malicious Rule Author}: Contributes logic to the registry. & Code execution within Wasm sandbox. \\
\bottomrule
\end{tabular}
\end{table}

\textbf{Security Assumptions.}
We assume the Linux kernel and eBPF verifier are part of the TCB. An attacker who compromises the kernel ($\mathcal{A}_{ker}$) is out of scope, as they can bypass any monitoring. However, \textsc{WasmSentinel} is designed to detect $\mathcal{A}_{loc}$ \textit{during} the transition from user to kernel compromise (e.g., via CVE-2024-1086).

\subsection{Security Goals}
\label{sec:threat-goals}

\textsc{WasmSentinel} aims to satisfy the following security properties:

\begin{enumerate}
    \item \textbf{Detection Integrity (G1):} Malicious syscall sequences must trigger an alert with high probability ($P_{alert} > 1 - \epsilon$).
    \item \textbf{Sandbox Isolation (G2):} A malicious rule $\mathcal{A}_{rule}$ cannot access memory, files, or network resources outside its Wasm linear memory.
    \item \textbf{TOCTOU Protection (G3):} The system must prevent Time-of-Check Time-of-Use attacks on security events transferred via the zero-copy channel.
\end{enumerate}
